# STRATEG-RUSSIA — Рабочий мессенджер

🧊 **Реальный чат между живыми клиентами**

## Что это

STRATEG-RUSSIA — полноценный мессенджер без демо-заглушек. Общение происходит ТОЛЬКО между реальными пользователями через WebSocket.

### ✅ Реальные возможности
- Генерация уникального STRATEG-ID при запуске
- Отправка сообщений другим пользователям по STRATEG-ID
- QR-код для быстрого обмена ID
- Глаза-сущности показывают состояние соединения
- Хранение сообщений 24 часа для оффлайн пользователей
- Никаких уведомлений, никакого давления

### ❌ Чего НЕТ (специально)
- Автоответы AI
- Фейковые сообщения
- Демо-режимы
- "Онлайн" статусы
- Уведомления

## Быстрый запуск

### 🚀 Для пользователей
1. **Запустите сервер**: `node server/coordinator.js`
2. **Откройте клиент**: `npm run dev`
3. **Обменяйтесь STRATEG-ID** с другим пользователем
4. **Отправляйте сообщения**

### 🧪 Тестирование между устройствами
1. **ПК**: Откройте `http://localhost:5173`
2. **Телефон**: Откройте тот же IP в браузере
3. Каждый получит свой STRATEG-ID
4. Обменяйтесь ID и общайтесь

### 📱 Тестирование с QR
1. **Удерживайте кнопку "📱 QR" 5 секунд**
2. **Появится QR-код с вашим STRATEG-ID**
3. **Отсканируйте на другом устройстве**
4. **Начните общение**

## Использование

1. **Получение STRATEG-ID**: При первом запуске приложение автоматически сгенерирует уникальный ID (например: `STRATEG-ABC123DEF`)

2. **Обмен ID**: Чтобы общаться с другим пользователем, обменяйтесь STRATEG-ID

3. **Отправка сообщений**:
   - Введите STRATEG-ID получателя в поле "STRATEG-ID получателя"
   - Напишите сообщение
   - Нажмите Enter или кнопку "Отправить"

## Поддержка

При возникновении проблем:
1. Проверьте, что сервер запущен (`npm run server`)
2. Проверьте консоль браузера на ошибки
3. Убедитесь, что порты 8080 (WebSocket) и 5173 (Vite) свободны
